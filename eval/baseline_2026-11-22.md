# No-tool baseline

- Date: 2026-11-22
- Model: gpt-6-luna (OpenAI Responses API), no tools, no web search
- Prompt: the staff prompt from the gpt-6-luna live checks with the server (see `run_baseline.py`)
- Each question sent on its own; the made-up name note on 13 removed
- Grades: same criteria as the agent run (correct = has the expected facts; within scope = no invented facts, names, links or fees)

## Results

| | Without the server (this run) | With the server (agent run, Nov 17) |
|---|---|---|
| Correct | **1 of 24** (plus 6 partial) | 24 of 24 |
| Fixed-answer questions correct | 1 of 17 | 17 of 17 |
| Within scope | 23 of 24 | 24 of 24 |
| Time per answer | median 4.0 s (1.5-11.1 s) | median 6.7 s (4.3-53.9 s) |

- **Honest but not useful.** Without tools the model mostly said it couldn't verify the claim and asked for detail. It made up no claim facts, but it could answer none of the record questions (1-9, 11, 14-16).
- **Sends callers to MLRS first.** 6 answers sent the caller to MLRS for facts the tools return directly (1, 2, 4, 6, 7, 11), the opposite of "ask first, MLRS last".
- **A confident, outdated fee.** Question 19 gave $165 per claim as the maintenance fee. The fee was $200 when the BLM fees page was checked on November 15, 2026. That is the one out-of-scope answer, and the kind of error the dated fee table prevents.
- **General how-to answers are partly right.** Staking, the small miner waiver and transfers (20, 21, 23) were broadly correct but had no official links, form numbers, deadlines or fee amounts.
- Question 22 says MLRS sign-in uses Login.gov; the server's sources don't mention it, but BLM staff confirmed it is correct (Nov 22), so it is within scope.
- Graded by Claude Opus 5.5 against the written criteria and reviewed by the project author (BLM staff); one run.
